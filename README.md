# 下班倒计时

一个可以直接部署到 GitHub Pages 的静态网页：18:00 下班倒计时、上下班打卡、工作时长、休息日切换、月历记录与 A/C 双主题。

## 本地打开

直接双击 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 数据与隐私

- 打卡数据保存在当前浏览器的 `localStorage` 中。
- 分享网页链接不会分享你的记录；每位访客拥有自己的本地数据。
- 同一设备、同一浏览器用户资料中的访客会共用本地记录。
- 可以在打卡日历里导出或导入 JSON 备份。

## 发布

仓库发布到 GitHub 后，在仓库设置中启用 GitHub Pages，选择从默认分支根目录部署即可。
