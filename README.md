# 下班倒计时

一个可以直接部署到 GitHub Pages 的静态网页：下班倒计时、上下班打卡、摸鱼计时、实际工作时长、休息日切换、月历记录与 A/C 双主题。

## 使用说明

- 第一次点击“上班打卡”或“下班打卡”，记录当前时间。
- 已打卡后，单击对应按钮可以确认取消，双击或双击轻触可以修改时间。
- 上班后点击“开始摸鱼”记录暂停，再次点击结束；下班时会自动结束进行中的摸鱼。
- 实际工作时长按照“下班 − 上班 − 累计摸鱼”计算，日历中会保留当天明细。
- 网页不预设固定休息日；点击日期旁的“今天休息”后，日历才会标记当天为休息日。

## 本地打开

直接双击 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 数据与隐私

- 打卡数据保存在当前浏览器的 `localStorage` 中。
- 分享网页链接不会分享你的记录；每位访客拥有自己的本地数据。
- 同一设备、同一浏览器用户资料中的访客会共用本地记录。
- 可以在打卡日历里导出或导入 JSON 备份。

## 发布

仓库发布到 GitHub 后，在仓库设置中启用 GitHub Pages，选择从默认分支根目录部署即可。
